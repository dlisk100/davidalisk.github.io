# Hosted view restoration contract

The Methods→Back gate compares every state field. Only `camera.center` and
`selection.point` are generated by inverse projection and may accumulate
floating-point round-trip noise. Each axis must differ by at most 1e-9 degrees
**and** the Euclidean projected displacement at the actual live camera must be
at most 0.01 CSS pixels. The gate records both deltas. A separate before/after
measurement checks actual selection screen positions and raw camera translation
under the two live transforms; raw zoom remains exact. This is not a raster
comparison, source-coordinate precision change, or UI behavior change.

Version, zoom, unit, selection type/ID, layer identities/order and all other
state fields remain exact. Source facts/metadata are independently compared
exactly. Methods return hash is preserved literally and its decoded JSON must
equal the pre-navigation state. Saved JSON is exact before inverse projection.
The existing share contract intentionally strips query parameters; it does not
preserve arbitrary search queries. The lower-48 codec has no bearing/rotation;
longitude is a literal [-180,180] value, so a 360-degree rewrite is rejected,
not normalized into silently accepted serialization.

RED: the observed camera 1.4210854715202004e-14° and selection
7.105427357601002e-15° drift failed the old exact comparator. GREEN: eight
regressions pass with coordinate-only comparison. An in-memory pixel-gate
mutation made both 0.02px/tiny-geographic camera and selection regressions fail;
one-pixel same-ID camera, missing projection, source-ID/order, source metric,
unit/layer/category and zoom changes remain rejected. No baseline copy tests
were changed: their three inherited failures remain separately disclosed.

Hosted Chromium metrics/touch are installed before each boot. The 393x360 case
models keyboard-height geometry only, not a real software keyboard, iPhone
Safari, safe-area chrome or X embedded browser. The job is bounded to 15 minutes,
with at most ten PNGs, allowlisted receipt/PNG uploads, no profile/environment
artifacts. Astro builds only on the hosted runner. No main merge, deployment,
media, data recalculation, renderer or worker/guard changes are authorized here.
